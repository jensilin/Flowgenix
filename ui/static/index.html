JSON → CSV (optional upload)

Accepts a JSON object, a JSON array, or NDJSON / JSON Lines (one object per line). The file is analyzed for its schema only — the generated flow reads real files with GetFile, flattens them with an auto-configured Jolt spec, and writes CSV with PutFile. Your upload is copied into the pickup directory so the flow produces output immediately. Processor class names and NAR versions always come from the detected NiFi version.

Untick a field to leave it out of the CSV — it is removed from the Jolt spec and the writer schema, so NiFi never writes that column.

Golden file (optional): compare the flow's real output against a file you know is correct

Drop the CSV you expect the flow to produce. After deploy, the test suite reads the file the flow wrote and reports whether it matches (line-by-line, trailing whitespace ignored).

NiFi migration (upgrade an existing flow)

Accepts a NiFi 1.x template (.xml) or a flow definition (.json) from either NiFi 1.x or 2.x. A .json file is never assumed to be 2.x — the source version is read from the NAR bundle versions inside the file, and you are asked to pick it only when the file genuinely does not say. Your upload is never modified.
