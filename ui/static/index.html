    Migrate a NiFi flow between versions

    Flowgenix reads a 1.x XML template or a JSON flow definition from any release and writes a file the target version can import.

    1. Drop a file on the left, paste its text, or load the sample.
    2. Check the detected version and pick a target.
    3. Tick the suggested changes you want, check them in Preview, then Generate and download.

    Suggested changes

    Nothing here is applied unless you tick it. Format changes always happen: XML to JSON, the NAR bundle version and the target's JSON fields.
